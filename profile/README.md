# Colosseum Arena

개발 생산성과 협업 경험을 더 빠르고 단단하게 만드는 도구와 서비스를 만듭니다.

## 우리가 만드는 것
- **Colosseum-arena-ServiceRepo**: 서비스 백엔드 및 운영 기반 저장소
- 앞으로 CLI, 자동화, 협업 워크플로우를 중심으로 제품을 확장합니다.

## 목표
- 개발자가 더 적은 반복 작업으로 더 빠르게 결과를 만들 수 있도록 돕기
- 팀이 일관된 브랜치/PR/배포 흐름으로 협업할 수 있게 만들기
- 로컬 개발 경험과 운영 경험을 함께 개선하기

## 현재 저장소
- [Colosseum-arena-ServiceRepo](https://github.com/Colosseum-arena/Colosseum-arena-ServiceRepo)

## 협업 방식
- 기본 브랜치: `develop`
- 작업은 이슈 생성 후 브랜치를 분기해 진행합니다.
- 모든 PR은 `develop` 기준으로 리뷰 및 머지합니다.
