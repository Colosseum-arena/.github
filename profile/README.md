# Colosseum Arena

> 개발 생산성과 협업 경험을 더 빠르고 단단하게 만드는 팀

## 소개
Colosseum Arena는 개발자가 반복 작업보다 **문제 해결과 제품 개발**에 더 집중할 수 있도록,
서비스 백엔드, CLI, 자동화, 협업 워크플로우를 함께 설계하고 만들어갑니다.

## 우리가 집중하는 영역
- **서비스 백엔드**: 안정적으로 확장 가능한 서비스 기반 구축
- **개발자 도구**: CLI, 자동화, 운영 보조 도구 설계
- **협업 워크플로우**: 이슈, 브랜치, PR 중심의 일관된 개발 문화 정착

## Repository
- [Colosseum-arena-ServiceRepo](https://github.com/Colosseum-arena/Colosseum-arena-ServiceRepo)  
  서비스 백엔드와 개발 운영 흐름을 관리하는 메인 저장소입니다.

## Workflow
- 기본 브랜치: `develop`
- 모든 작업은 이슈 생성 후 브랜치를 분기해 진행합니다.
- 모든 변경은 Pull Request 리뷰 후 `develop`으로 머지합니다.

브랜치 예시:
- `feat/264-로드맵-수정-채팅-내역-조회-api-추가`

커밋 예시:
- `feat (#264) : 로드맵 수정 채팅 내역 조회 API 추가`

## Vision
우리는 단순히 기능을 추가하는 것을 넘어서,
**개발 경험 자체를 제품 경쟁력으로 만드는 팀**을 지향합니다.
